# Ecom_data_engineering_project
This project focuses on end-to-end data engineering pipeline to load data and transform ecommerce into an analytical data store. Using MySQL Workbench, i executed data cleaning and designed STAR Schema for ease in BI querying &amp; analytical reporting.

# 🛠️ Tech Stack & Tools
* Database Engine: MySQL Server
* IDE: MySQL Workbench
* Data Modeling Tool: Draw.io
* Language: SQL (DDL, DML)
